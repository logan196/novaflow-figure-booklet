# Novaflow · The Figure Booklet (neuro-omics 2023–26)

**Live:** https://logan196.github.io/novaflow-figure-booklet/

This site is an interactive version of the Novaflow figure-package booklet. It covers 98 plotting and analysis packages used in neuroscience bulk, single-cell and spatial omics papers. Packages are ranked by how often they appear in the Methods sections of a 17,768-paper open-access corpus (Europe PMC, 2023–26). There are 329 recreated figure variations, each with its runnable script.

- `index.html`, `js/app.js`, `css/site.css`: a static single-page app with no build step.
- `data/catalog.json`: generated by `build_site.py` from the catalog xlsx/CSVs and `booklet/entries.json`.
- `img/thumbs` and `img/full`: WebP thumbnails and the larger WebP images used in the lightbox. `img/orig` holds the original PNGs for download.
- `scripts/`: the recreation scripts.
- `downloads/`: a compressed PDF of the booklet (222 pages).

Caveats: the corpus is open-access only, and a Methods mention is not proof that the package made a given figure. See the Methods page.
